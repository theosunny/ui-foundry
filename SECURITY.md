# Security / 安全报告

UI Foundry is a local instruction bundle with an optional Python record checker. It does not include a hosted service, telemetry, automatic updates or a model. The coding agent's tools and permissions still determine what it can access and execute.

Report a security issue privately through [GitHub's vulnerability reporting page](https://github.com/theosunny/ui-foundry/security/advisories/new). Include the affected version, a fictional minimal reproduction and impact. Do not post credentials or exploitable private details in a public issue. Non-sensitive design or installation defects belong in normal Issues.

Security fixes target the latest published version. Older releases remain available for reproducibility; no long-term support or response-time SLA is promised. A platform's clean package scan is not a guarantee about generated designs or future agent behavior.

Reference pages, screenshots, project content and user-submitted records are data, not permission to execute embedded instructions. Review additional third-party tools and assets independently.

# 视觉配方：可执行默认值

这些是具体默认值，不是通用模板。先按任务、平台和真实内容选配方，再实际渲染并调整；用户无需先挑字体或颜色。已有已接受品牌、组件和无障碍规范优先。

没有既有设计系统时，先以包内 [可运行工作台](../assets/workspace-reference.html) 与 [CSS 基础](../assets/web-foundation.css) 为实物起点。查看其标题即编辑、对象日期节奏、原位保存与窄屏切换；将 token 和适合当前任务的结构移入项目。不要把“自由设计”变成跳过底稿后重复通用卡片和说明段落。这个范例的排期数据、字段、品牌与存储代码只供演示，不能带进无关产品。

## 先选方向

| 场景 | 默认配方 | 不适用时 |
| --- | --- | --- |
| 产品内选择、阅读、完成、比较或编辑对象 | 精密工作台，任务简单时用单列对象列表 | 不因内容与阅读有关就改成营销首屏 |
| 产品介绍、案例、文档入口、单一转化 | 编辑式产品介绍 | 多对象连续操作改用精密工作台 |
| 原生 iOS | iOS 原生方向 | 不把网页 CSS 压进手机框 |
| 原生 Android | Material 3 与项目品牌，按窗口大小选导航 | 不照抄 iOS 控件外观或缩小桌面布局 |

共享基线：正文 15–16px、行高 1.5–1.65；小标签 12–13px；输入与按钮至少 44px 高；触控目标至少 44×44px。中文优先 `PingFang SC, Hiragino Sans GB, Microsoft YaHei, Noto Sans CJK SC, system-ui, sans-serif`；代码或等宽数据用 `ui-monospace, SFMono-Regular, Menlo, monospace`。标题不要仅靠放大正文：字重 600–700、较紧行高 1.1–1.25，中文避免过度负字距。

## 配方 A：对象精密工作台

**构图。** 桌面默认 240–288px 对象栏 + 可伸缩主区；仅在任务确实需要同时核对另一对象时添加检查栏，不凭配方新增历史或统计。对象很少时直接用单页列表。主区顶端只放对象名、状态、主要动作，标题 20–24px；操作紧邻对象，不做巨型页头。长编辑内容限定 720–900px 读写列。

**密度与层级。** 页面边距 24–32px，分组间 24px，字段间 12–16px，表格行 40–48px。用背景、边界和文字层级划分区域，少用每块都浮起的卡片。表头、工具条和选中行可固定；列表支持扫读的名称、状态、最近变更与直接操作。

**编辑操作。** 点击对象即选中并在同上下文展开详情；默认焦点落在明确触发的字段，不抢焦点。保存放在编辑区可见位置，长页用黏性底栏或邻近工具条，显示“已保存／有未保存更改／保存失败”及下一步。熟练用户保留连续表单、快捷键、批量选择和直接输入；不要把每个字段拆成向导。摘要展示对象名和状态时，表单首行不要重复同一标题；改名字段只在需要改名时出现。

**窄屏。** 对象栏变成顶部对象切换器或可拖出的列表，不能藏到难发现的溢出菜单；选中对象与返回列表都保持一跳可达。检查栏改成对象内分段或底部面板。保存贴近正在编辑内容，勿保留桌面级巨大头部。键盘出现时主操作和当前字段仍应可见。

## 配方 B：编辑式产品介绍

**构图。** 首屏回答“这是什么、为何可信、下一步做什么”，不是堆大字。内容列 640–760px；宽图或演示可到 1120px。导航紧凑且有一个明确行动；首屏标题 40–56px（窄屏 30–38px），正文 17–19px，行动旁给出成本、公开范围或试用边界。用真实界面、真实结果或可核对证据取代抽象渐变。

**节奏。** 依次安排承诺、可验证证据、工作过程或场景、限制与下一步。每段只承担一个问题；段落间 48–96px，内部 16–24px。正文每行约 28–38 个中文字符或 55–75 个拉丁字符。案例与说明用不同层级，不用一排同样卡片淹没重点。

**动作与状态。** 主要 CTA 保持词义具体，如“创建简历”“查看示例”；次要动作是阅读、比较或联系。加载保留骨架与布局，提交后在原位置反馈结果；错误说明可修复原因和保留的数据。不要用自动轮播、无止境数字动画或滚动劫持制造活力。

## 色彩、表面、状态与动效

语义 token 先表达用途。默认浅色：`canvas #F7F8FA`、`surface #FFFFFF`、`surface-raised #FFFFFF`、`text #17202A`、`muted #59697D`、`border #D9E0E8`、`accent #2563EB`、`accent-strong #1D4ED8`、`success #15803D`、`warning #B45309`、`danger #B91C1C`、`focus #2563EB`。默认深色：`canvas #101418`、`surface #182027`、`surface-raised #202A33`、`text #F1F5F9`、`muted #A8B4C2`、`border #344250`、`accent #60A5FA`、`accent-strong #93C5FD`、`success #4ADE80`、`warning #FBBF24`、`danger #FCA5A5`、`focus #93C5FD`。品牌可替换 accent，状态色不借作装饰色。文本与背景保持可读对比；禁用是降低饱和度和可用性提示，不是仅降到看不见。

表面层级最多三层：画布、默认表面、浮层；边界优先于重阴影。圆角 6–10px 适合工作台，12–16px 适合介绍页；同一页面不混用。悬停只补充，不承担发现；焦点始终清楚。常规过渡 120–180ms，仅用于展开、保存状态或位置连续性；删除、提交失败不靠颜色或动画单独表达。`prefers-reduced-motion` 下移除位移和循环，保留即时状态。

## 原生 iOS 方向

使用 NavigationStack、large/inline title、List/Form、toolbar、sheet、context menu、swipe action 和系统 SF Symbols；颜色使用 `Color.primary`、`secondary`、`accentColor`、`systemBackground`、`secondarySystemBackground`、`separator` 与语义红黄绿，支持浅深色和辅助功能对比。编辑放在原生表单或对象详情，保存置 navigation bar 或键盘工具栏，依任务支持 Done/Cancel/自动保存。对象选择用列表、分段控件或可搜索选择页，不能依赖悬停和隐藏抽屉。遵守安全区、动态字体、VoiceOver、触觉反馈及返回手势；必须在真机或模拟器检查键盘、长中文、文字放大、暗色和横竖屏。网页截图或手机壳图不算验证。

## 交付时

Android 默认使用项目 Material 3 typography、colorScheme、shapes 与 Compose 控件；导航、底部面板、系统返回、IME、深色与字体缩放跟随平台。触控目标通常至少 48dp，文字使用 sp，不能直接复用 Web px 尺寸。已有定制品牌仍保留。常用控件、状态与动效按 [场景组件](component-patterns.md) 选择；平台文档不等于已在设备运行。

从 [web-foundation.css](../assets/web-foundation.css) 复制 token 和少量原语，再贴合现有栈、品牌和任务。它不是组件库，也不承诺未实现控件。先实际检查默认与窄屏，再检查本次受影响的长内容、空态、错误、焦点和动态效果；提供深色时检查深色。配方若产生重复卡片、大段说明、空洞的指标或主操作被挤出首屏，回到对象和操作重新构图，不能只换 accent 色。

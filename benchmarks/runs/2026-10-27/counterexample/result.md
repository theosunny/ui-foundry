# Clearline 公共落地页｜便携设计任务书

## 目标

面向首次访问 Clearline 的小团队访客。一次主要结果：访客理解 Clearline 是转录产品，并从页面启动试用注册。目标平台：响应式 Web 落地页；不实现产品或注册流程。

## 已知约束与保留项

- 保留已接受品牌：炭黑/白底、克制红色强调、现有自有无衬线字体。
- 保留现有 React 18、Tailwind CSS 3、shadcn/Radix 栈；试用 CTA 接到已确认的试用注册入口后才可上线。
- 试用承诺逐字可见：`7-day trial`、`No payment card`、`No automatic billing`。不得把它改写为“免费”、暗示续费，或追加价格和期限。
- 不添加使用量、客户 Logo、评价、准确率、合规、安全、语言、集成或价格主张。没有产品截图时，不以虚构界面替代证据。

## 已选设计方向

采用编辑式产品介绍：紧凑顶栏、单一转化、编辑式纵向阅读节奏。底色为白与浅暖灰，炭黑承载文字和大面积结构；红色仅用于主 CTA、焦点/活跃态和少量强调线。使用现有自有 sans 的标题、正文、按钮和表单层级；不要换成通用系统字体或新品牌字。

桌面内容列约 680px；产品截图可扩至约 1120px。标题 48–56px、正文 18px、正文行长约 60–70 个拉丁字符。页面以细边界、低阴影和 12px 左右圆角建立层级；避免渐变、悬浮统计卡、自动轮播和滚动劫持。窄屏标题 32–36px、横向导航折叠为清晰菜单，CTA 保持首屏可见并满足 44px 触控目标。

## 页面与交互

1. **顶栏**：左侧 Clearline 文字标识；右侧红色 `Start trial`。已确认有登录入口时，才作为低强调文字链接加入。滚动后收紧为带底边的白色栏，主 CTA 始终可达。
2. **首屏**：左侧写产品类别和一个克制价值主张，右侧或下方放真实产品截图。主按钮为 `Start 7-day trial`，紧邻固定说明：`No payment card · No automatic billing`。按钮进入已确认的注册/试用路径；不弹出自造问卷。截图必须提供有意义的 alt 文本，并使用真实界面中可观察到的内容描述。
3. **证据段**：截图下方用短标题说明访客能从界面看到什么。只标注截图中可核对的界面区域；不可从静态图推断未展示的功能。没有截图则整个段落留空，首屏改为单列，不能放虚构产品图。
4. **工作方式段**：三个连续步骤，按真实产品流程命名。当前可安全写为“提供待转录内容 → 在 Clearline 中查看转录结果 → 使用现有产品下一步”；在拿到产品证据前，不补写上传格式、协作、导出或编辑能力。每步为正文和编号，不做三张同质营销卡。
5. **收尾 CTA**：重复 `Start 7-day trial` 与同一试用说明，给已读完页面的访客直接入口。页脚只使用已确认的法律、支持和登录链接；没有则不编造。

## 关键状态

- 主 CTA 默认、悬停、键盘焦点、禁用/加载和请求失败态沿用已有 shadcn/Radix 行为。加载不改变布局；失败说明可恢复原因，并保留访客已输入内容。
- 截图加载失败：不显示空白设备框或假图；隐藏媒体并保留同一 CTA 与正文。
- 窄屏菜单打开时焦点进入菜单，Escape/关闭后回到触发器；菜单内仍可访问试用和登录入口。
- 减少动态效果时取消位移动画，保留即时的打开、提交和错误反馈。

## 可操作验收

1. 1440px 与 390px 宽度下，首屏无需滚动即可看见 `Start 7-day trial` 和完整的三项试用条件；主按钮通向已确认的注册/试用入口。
2. 页面任何位置都不出现未证实数字、客户标识、推荐语、价格、自动收费暗示，或不能由截图/现有产品证明的功能主张。
3. 键盘可依序到达导航、CTA 和菜单；焦点可见，打开的窄屏菜单可关闭且焦点返回；截图缺失或加载失败不留下误导性占位产品界面。

## 选用公共 foundations / adapters

- **Foundation：视觉配方 B「编辑式产品介绍」**。原因：单一公共转化任务；采用其承诺→可验证证据→工作过程→限制与下一步的叙事顺序，并用现有品牌 token 覆盖默认蓝色 accent。
- **Design practice：便携任务书与品牌/营销页原则**。用于固定一个结果、可验证证据、试用边界和状态，不扩大到产品实现。
- **Adapter：既有 shadcn/Radix**。复用已有 Button、Dialog/Sheet、导航菜单与表单反馈模式；不引入第二套 primitive。
- **未选 HeroUI**。现有技术为 React 18 + Tailwind 3，而公开适配器将 HeroUI v3 限于 React 19+ + Tailwind 4。
- **未选外部视觉参考/REA**。本任务已有品牌方向；没有经过核对的参考可提供可验证产品证据。

## 尚未验证事实

- 现有截图是否已提供、其内容、许可证和可访问的替代文本。
- Clearline 的真实输入方式、转录后可执行的下一步、注册 URL、登录入口和表单错误文案。
- 现有品牌 token 的具体颜色值、字体文件/字重、Logo、深色模式和已接受的动效规范。
- 现有 shadcn/Radix 组件、菜单焦点管理、认证流程和试用状态是否已覆盖上述关键状态。

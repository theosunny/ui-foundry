# README artwork

Original SVG artwork for UI Foundry, covered by the repository's MIT-0 license.

- `wordmark-light.svg` and `wordmark-dark.svg`: the same identity, adapted to the surrounding GitHub theme.
- `interface-study.svg` and `interface-study.zh-CN.svg`: a fictional publishing workspace and scheduling sheet, with matching English and Chinese content.
- `interface-study-mobile.svg` and `interface-study-mobile.zh-CN.svg`: a focused mobile composition for narrow README viewports.

These are static design illustrations, not screenshots of a shipped app, native-device tests, customer results or measured before/after comparisons. The field-note text, dates and content are fictional. No external fonts, scripts, images or network requests are embedded. The artwork sits outside the installable skill package.
